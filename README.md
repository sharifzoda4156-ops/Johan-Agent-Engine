## Замеры

Задания 003–007 — набор для регулярного замера движка: после каждого этапа доработки одни и те же ТЗ прогоняются заново и сравниваются три числа: доля решённых задач, $ на задачу и время на задачу. Задача считается решённой, если проходят скрытые приёмочные тесты; агент их не видит. Эталонные решения и скрытые тесты хранятся вне этого репозитория. ## Компонент `tag-input`

Поле ввода тегов на чистом DOM, без фреймворков, сборщиков и CSS-библиотек. Реализация — `src/tagInput.js`, именованный экспорт `createTagInput`.

### API

`createTagInput(container, options)` создаёт компонент внутри элемента `container` и возвращает объект:

| Метод | Описание |
| --- | --- |
| `getTags()` | Возвращает копию текущего массива тегов в порядке добавления. |
| `setTags(tags)` | Заменяет набор тегов. `onChange` не вызывается. Каждый тег нормализуется; недопустимый тег или превышение `maxTags` (после удаления повторов) → `TypeError`, состояние не меняется. |
| `destroy()` | Удаляет разметку компонента из контейнера и все обработчики. После вызова события на старых узлах ни на что не влияют. Повторный вызов безопасен. |

### Опции

| Опция | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `initial` | `string[]` | `[]` | Начальный набор тегов. Нормализуется и проверяется так же, как в `setTags`; при ошибке создание падает с `TypeError`. |
| `maxTags` | `number` | `Infinity` | Максимальное число тегов после удаления повторов. |
| `onChange` | `(tags: string[]) => void` | — | Вызывается при изменении набора тегов пользователем (добавление, удаление, ввод). |
| `disabled` | `boolean` | `false` | Блокирует ввод и удаление тегов. |

### Поведение

- `Enter` и `,` в поле ввода добавляют тег: значение нормализуется, пустое — игнорируется, дубликат — не добавляется.
- Вставка текста с запятыми разбивается на части; обрабатываются все части до последней запятой, остаток остаётся в поле.
- `Backspace` в пустом поле удаляет последний тег.
- `blur` фиксирует набранное значение как тег.
- Клик по кнопке удаления убирает соответствующий тег.
- При превышении `maxTags` или недопустимом значении поле помечается `aria-invalid="true"`.

### Пример подключения

~~~html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="utf-8" />
    <title>Tag input</title>
  </head>
  <body>
    <div id="tags"></div>

    <script type="module">
      import { createTagInput } from './src/tagInput.js';

      const container = document.getElementById('tags');
      const tagInput = createTagInput(container, {
        initial: ['javascript'],
        maxTags: 5,
        onChange: (tags) => console.log('tags:', tags),
      });

      console.log(tagInput.getTags()); // ['javascript']
    </script>
  </body>
</html>
~~~
