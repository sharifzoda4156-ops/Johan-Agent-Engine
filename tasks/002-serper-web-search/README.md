# Тест № 002 — веб-поиск через Serper в плейн-чате (сравнение с эталоном)

Реальное задание из разработки Johan: добавить веб-поиск через Serper API в плейн-чат бэкенда (Node.js, Postgres) с тумблером, учётом расхода и лимитом частоты. Это не изолированный проект: код относится к приватному backend Johan, здесь опубликованы только материалы сравнения.

## Состав

- `prompt.txt` — исходное ТЗ, которое получил агент.
- `agent/pr104-first-version.patch` — первая версия агента (diff, один коммит).
- `agent/pr105-fixes.patch` — что исправили поверх: двойной поиск при включённом глобусе композера, порядок проверки лимита тарифа, стабильный код `web_search_rate_limited`, запись флага через `db.js`.
- `agent/final/` — итоговые файлы: `lib/webSearch.js` и два self-теста.
- `reference/pr6.patch` — эталонная реализация (Opus) относительно того же состояния кода.
- `reference/checklist.json` — чек-лист приёмки эталона.

## Как читать

Сравнивайте `agent/final/lib/webSearch.js` и `reference/pr6.patch` по чек-листу. Патчи предназначены для чтения и не применяются к этому репозиторию.

Реальный вызов Serper и реальный LLM при проверке не запускались; тесты работают на моках.
