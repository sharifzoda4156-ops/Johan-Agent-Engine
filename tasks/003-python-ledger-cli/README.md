# Тест № 003 — Python CLI: отчёт по балансам из CSV

**Тип:** Python, новый проект с нуля. **Размер:** малый.

## Цель

Утилита читает CSV с проводками и печатает балансы по счетам в JSON. Проверяем точность ТЗ: Decimal-арифметику, валидацию, коды выхода, фильтры.

**Стек:** Python 3.11+, только стандартная библиотека. Тесты на `unittest` (`python -m unittest`). Без сторонних пакетов, сети и файлов вне рабочей папки.

## Интерфейс

Пакет `ledger/` в корне репозитория. Запуск из корня:

```
python -m ledger report FILE [--from YYYY-MM-DD] [--to YYYY-MM-DD] [--account PREFIX]
```

## Входной CSV

- UTF-8, допускается BOM. Разделитель `,`, кавычки по правилам модуля `csv`.
- Первая строка — заголовок. Обязательные столбцы: `date`, `account`, `amount`, `currency`. Необязательный: `memo`. Порядок столбцов любой. Другой или повторяющийся столбец, отсутствие обязательного — ошибка в строке 1.
- `date` — существующая календарная дата `YYYY-MM-DD`.
- `account` — сегменты через `:`, каждый непустой, без пробелов по краям сегмента (`Assets:Bank`, `Расходы:Еда`).
- `amount` — `^-?\d+(\.\d{1,2})?$` (без `+`, экспоненты, пробелов).
- `currency` — ровно три заглавные латинские буквы.
- Полностью пустые строки (все поля пустые) пропускаются. Строка с другим числом полей, чем в заголовке, — ошибка.

## Вывод

Успех: код 0, в stdout один JSON-объект (и перевод строки):

```json
{"accounts":[{"account":"Assets:Bank","currency":"USD","balance":"12.30"}],"total_transactions":3}
```

- Баланс — сумма `amount` по паре (счёт, валюта) только для проводок, прошедших фильтры. Точная десятичная арифметика, без float.
- `balance` — строка ровно с двумя знаками после точки; ноль всегда `"0.00"` (не `"-0.00"`).
- Пары с нулевым итогом выводятся.
- Сортировка по `account`, затем `currency` (обычное сравнение строк Python).
- `total_transactions` — число проводок после фильтров.

Фильтры:
- `--from` / `--to` — включительно; невалидная дата или `from > to` — код 2.
- `--account PREFIX` — сам счёт и его подсчета: `Assets` подходит для `Assets` и `Assets:Bank`, но не для `AssetsX`.

## Ошибки

- Ошибка данных: код 2, stdout пуст, в stderr первая найденная ошибка в виде `line N: <причина>`, где N — номер строки файла (заголовок — 1). Весь файл проверяется до вывода: частичного отчёта не бывает.
- Файл не найден / не читается: код 1, сообщение в stderr.
- Неверные аргументы командной строки: код 2.
